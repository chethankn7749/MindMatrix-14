# Hasta-Kala Shop

Android app for artisan sales, inventory, analytics, and income tracking.

## Stack

- Kotlin
- XML layouts
- Material 3
- Room-based local authentication
- Room Database
- MPAndroidChart
- RecyclerView
- Navigation + Bottom Navigation

## Setup Notes

1. Open this folder in Android Studio.
2. Let Android Studio generate or sync the Gradle wrapper if `gradle-wrapper.jar` is missing.
3. Build and run on an emulator or device.

## Package

`com.hastakala.shop`
